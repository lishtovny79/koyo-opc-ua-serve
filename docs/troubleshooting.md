# Диагностика неисправностей

[English version](en/troubleshooting.md)

| Симптом | Что проверить |
| --- | --- |
| Значения PLC не обновляются | IP PLC, UDP-порт 28784, маршрутизацию, firewall и настройки Ethernet-интерфейса контроллера. |
| OPC UA-клиент не подключается | TCP-порт 4840, firewall хоста и настроенный endpoint. |
| Теги отсутствуют | Колонки CSV, поддерживаемую нотацию адресов и лог старта сервера. |
| Новый тег не появился | `Objects/ServerStatus/LastTagOperation`: там указана ошибка проверки или подтверждение добавления. |
| Нужен backup тегов | Вызовите `Objects/TagManagement/BackupTags`; файл появится в `plc.backup_directory`. |
| Запись не работает | `Client Access`, тип данных, режим PLC и логи сервера. |
| `AddTag`/`BackupTags` используют старый код | Пересоберите Docker-образ без кэша по инструкции в [установке](installation.md). |

При потере связи сервер оставляет последние значения в кэше.
`Objects/ServerStatus/PlcOnline` показывает успешность последнего обмена с PLC.
Пока он имеет значение `false`, считайте значения устаревшими.
