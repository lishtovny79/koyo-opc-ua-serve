# Экспорт тегов Kepware

[English version](en/tag-export.md)

Экспортируйте теги в CSV со стандартными колонками Kepware. Обязательные поля:

- `Tag Name`
- `Address`
- `Data Type`
- `Client Access`

Поддерживаемые типы: `Boolean`, `Word`, `BCD`, `LBCD`, `Float`.

Имя тега с точками создаёт папки в OPC UA-дереве. Например,
`Mixer.Speed.Setpoint` превратится в путь:

```text
Objects/Mixer/Speed/Setpoint
```

Не добавляйте производственные CSV в Git, если имена или адреса раскрывают
информацию об оборудовании. Для демонстраций и CI используйте небольшой пример
из `examples/`.

Импорт CSV необязателен. При `plc.tags_csv = ""` сервер загружает ранее
сохранённые в SQLite теги, а при первом старте работает с пустым каталогом.
